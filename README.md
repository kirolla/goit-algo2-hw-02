## 🧠 Завдання 1: Пошук мінімального та максимального елементів

### 📌 Умова
Реалізувати функцію для знаходження мінімального та максимального значення в масиві, використовуючи підхід «розділяй і володарюй».

### ✅ Реалізація
- Використано рекурсивний підхід
- Масив ділиться на підмасиви
- Результати об’єднуються після обробки

### ⚙️ Складність
- Часова складність: **O(n)**
- Просторова складність: **O(log n)** (через рекурсію)

### 📥 Вхідні дані

### 📤 Вихідні дані
Кортеж:
(min, max)

## 🖨️ Завдання 2: Оптимізація черги 3D-принтера

### 📌 Умова
Розробити програму для оптимізації черги друку з урахуванням:
- пріоритетів
- обмежень принтера
- можливості групування моделей

---

### ✅ Реалізація
Використано **жадібний алгоритм (Greedy)**:
- Завдання сортуються за пріоритетом
- Формуються групи моделей
- Враховуються обмеження:
  - максимальний об’єм
  - максимальна кількість моделей
- Час друку групи = максимальний час у групі

---

### ⚙️ Вхідні дані

```python
print_jobs = [
    {
        "id": "M1",
        "volume": 100,
        "priority": 1,
        "print_time": 120
    }
]

constraints = {
    "max_volume": 300,
    "max_items": 2
}
```

---

### 📤 Вихідні дані

```python
{
    "print_order": ["M1", "M2", "M3"],
    "total_time": 360
}
```
